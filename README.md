# Campus Swap 🛍️

A Flask-based campus marketplace web application that allows students to **buy, sell, and manage items within their campus community**.

## 🚀 Features

- 🔐 User Registration & Login
- 👤 User Profile Management
- 🛒 Browse Marketplace Listings
- 📦 Add Items for Sale
- ✏️ Edit Existing Listings
- 🗑️ Delete Listings
- 📋 View Personal Listings
- 🔎 View Detailed Item Information
- 🎨 Responsive and Modern UI

## 🛠️ Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript
- Jinja2

### Backend
- Python
- Flask

### Database
- SQL
